# 🏥 Hospital Management System

A **Java-based desktop application** built using **Swing** and **MySQL** to manage hospital operations efficiently. This system provides an easy-to-use interface for managing patient records, doctor information, and appointment scheduling.

---

## 📌 Features

- 👨‍⚕️ Add, view, update, and delete patient and doctor records
- 📅 Schedule and manage appointments
- 📂 Search functionality for quick access to records
- 🔐 Login system for basic admin-level access
- 💾 Data persistence using MySQL and JDBC
- 🖥️ Clean GUI interface built with Java Swing

---

## 🛠️ Tech Stack

- **Language:** Java  
- **GUI Framework:** Java Swing  
- **Database:** MySQL  
- **Connectivity:** JDBC  
- **IDE:** Eclipse
